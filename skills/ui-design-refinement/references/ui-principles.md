# UI 方法与使用条件

本参考将 50 篇合集的设计方法整理为实施提示，编号与文章对应。方法参考《Refactoring UI》，业务状态与工程条件来自合集的案例应用。按当前页面的问题选择对应段落。

<a id="tasks"></a>

## 任务与范围：01—05

- **01 从用户任务确定界面结构。** 先列当前功能的信息与操作，再结合多个功能确定整体导航；已有有效导航可以沿用，单张截图不能证明历史设计顺序。
- **02 先结构，后细节。** 使用真实字段、间距和文字层级确定阅读顺序，灰度只辅助检查；滤镜不会自动重排列、字段或入口。
- **03 先交付可用功能。** 将独立扩展能力放入后续迭代，但保留本轮提交成功、失败与恢复路径；页面不要暗示尚未实现的能力。
- **04 协调风格与语气。** 字体、颜色、形状与文案共同支持产品定位。正式、亲和等属于取舍，风险和动作含义仍应准确。
- **05 限制无用途的选项。** 相同角色共享有限参数，有独立用途时再增加变体。不要把每个局部偏好都永久保存为例外。

<a id="hierarchy"></a>

## 信息层级：06—13

- **06 按任务安排层级。** 优先显示当前结论与允许的下一步，保留追溯字段。检查通过、制品可用与部署权限分别判断，失败时重新确定重点。
- **07 组合文字手段。** 用字号、字重和颜色共同区分主次，先保证可读。重要风险提示不能统一套用弱化的辅助样式。
- **08 字色适应背景。** 彩色面板的辅助字从实际背景出发选择，再检查对比；半透明白字需看混合结果，同色相不自动合格。
- **09 弱化竞争信息。** 主要元素可以保持不变，先减轻周围权重。未选中仍可用，不能被做成疑似禁用；焦点单独表达。
- **10 减少重复展示标签。** 格式和上下文清楚时可以合并字段，保留单位及当前、目标等身份区别。输入表单与按参数检索的配置表仍需标签。
- **11 语义与大小分开。** 依据内容关系选择标题级别，再用样式控制权重。不要为获得字号而跳选标题，也不要默认 h1 必须最醒目。
- **12 平衡图形重量。** 实心图标着色面积较大，可适度降低对比以配合文字；独立操作图标需保留可辨识度、名称与操作范围。
- **13 按当前任务区分按钮。** 主操作、次要与低频入口各有层级；危险含义不自动等于最强实底。最终确认步骤的主次应重新判断。

<a id="layout"></a>

## 布局与空间：14—19

- **14 从宽松处收敛留白。** 先比较明显宽松的方案，再收回无用空间。密集日志与确认页可以采用不同密度，留白为分组服务。
- **15 定义间距角色。** 相同内容关系复用相同档位，组内和组间保持区别。小尺度变化更敏感，大尺度可拉开，不以“全是某数倍数”代替体系。
- **16 宽度来自内容。** 短表单可设置上限，辅助说明可独立分栏。只有 1fr 分栏不能阻止无限增长；窄屏按合理顺序堆叠。
- **17 分配固定与弹性空间。** 稳定菜单可按内容确定宽度，主内容使用剩余空间。断点由内容失效决定，长字符串仍需换行或受控滚动。
- **18 独立调整窄屏尺寸。** 大标题可比正文缩小更多，按钮与内边距也可分别调整。溢出时考虑重排，不缩小整页掩盖问题。
- **19 用距离说明字段归属。** 标签、输入、帮助和错误组成字段组，组外距离大于组内。视觉分组配合真实标签关联，并用多行反馈验证。

<a id="type"></a>

## 文字排版：20—27

- **20 以用途组织字号。** 合并无意义的近似值，标题、主体与辅助信息复用档位。嵌套 em 字号受父级影响，需检查最终计算值；单位按用途选择。
- **21 使用实际样本选字体。** 在最终尺寸检查中文、标点、数字、版本与易混淆字符，也看所需字重和回退。字体类别本身不是质量结论。
- **22 控制正文行长。** 说明可以拥有独立宽度，日志与表格使用自己的策略。西文字符数经验不直接作为中文汉字数规定。
- **23 混合字号比较基线。** 同一行文字通常可共享 baseline；图标、头像、多行标题另行判断，避免为单个样本堆固定偏移。
- **24 标题与正文独立行高。** 行长、字号与字体共同影响下一行定位。标题可以适度收紧，正文保留阅读间隔，不能容忍字形裁切。
- **25 区分链接场景。** 正文链接需易于识别，密集关联区可通过字重和布局建立主次。关键入口在触屏和键盘下仍可发现。
- **26 按任务对齐内容。** 连续正文保持稳定行首，度量数据先统一单位与精度再考虑右对齐。缺失耗时不推断任务未完成，排序使用原数值。
- **27 局部比较字距。** 默认字距是起点，大写短标签可比较适度加宽。中文与代码标识不机械套用；CSS 调整不应向原字符串插入空格。

<a id="color"></a>

## 颜色与状态：28—34

- **28 区分模型与结果。** HEX 与 HSL 可以表示同一颜色，等价转换不会自动改善视觉。HSL 与 HSV/HSB 数值不能混用，L 不等于对比度。
- **29 颜色按职责分工。** 中性色支持结构，主色支持操作或选中，强调色支持必要状态。色板覆盖场景，不等于每屏用满，状态枚举保留真实含义。
- **30 用组件校准色阶。** 先选基础色与浅底、深字两端，再补中间档位。编号表示约定顺序，语义角色与色阶值分开管理。
- **31 多属性校准深浅。** 明度接近黑白时，感知鲜明程度可能变化；小幅色相变化可辅助调色，S 已为 100% 时不能继续提高。多变量对照不作单项因果结论。
- **32 连贯选择中性色温。** 冷灰与暖灰均可使用，表面、边界与文字一起判断。RGB 三通道相等才是纯中性灰，带蓝灰不应称为纯灰。
- **33 可读与主次一起判断。** 辅助标签可尝试浅底深字，再逐对测量。常见 AA 门槛为普通文字 4.5:1、大号 3:1；大号为至少 18pt 常规或 14pt 粗体及字体等效条件，不能简写为任意 18px。
- **34 颜色不独自承担含义。** 状态用明确文字与适当符号表达，颜色辅助扫描。灰度和色觉模拟是发现问题的手段，不等于全面无障碍验证。

对比度与字号细则见 [W3C 文字对比说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。必要控件或图形的对比另见 [W3C 非文字对比说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。比较门槛使用未四舍五入数值，按实际背景、字重、字号和状态核对。

<a id="depth"></a>

## 表面与层次：35—39

- **35 光源方向一致。** 需要深度时，先确定凸起或凹入，再安排高光与暗部。适度线索即可，边界、焦点和错误状态独立保留。
- **36 视觉高度配合真实层叠。** 为卡片、下拉和模态选适合角色的阴影。z-index 受层叠上下文影响，阴影不能解决裁切或替代关闭与焦点行为。
- **37 两层阴影分别控制。** 同一元素的大范围柔影表达投影，紧凑暗部表达接触关系。悬浮高度增加时接触暗部通常减弱，不是两层一律加黑。
- **38 扁平仍保留区域关系。** 用表面明暗与空间区分摘要和内嵌区域。明亮靠前是情境倾向，交互状态仍需可辨线索。
- **39 重叠需要空间。** 跨背景边界可表达前景，普通排列也可成立。为动态高度预留空间，长内容和窄屏需要时恢复普通流。

<a id="media"></a>

## 素材与预览：40—43

- **40 先判断素材质量。** 检查主题、主体、构图、光线与清晰度，再调卡片装饰。降质副本只作教学说明，使用真实素材需符合实际用途与来源约束。
- **41 稳定图上文字背景。** 从文字覆盖区域的最难读位置检查遮罩、裁切与摆放。加遮罩不自动合格，长标题、图片失败和不同裁切分别验证。
- **42 信息密度匹配尺寸。** 具体结果用关键区域，整体结构用概览或明确示意。高分辨率不能补救过密小图，图标细节也要符合目标大小。
- **43 预览与原件分别处理。** 固定容器稳定列表，contain 适合保留资料全貌，cover 适合可裁切内容。原件入口指向完整文件，极端比例和失败单独处理。

<a id="components"></a>

## 组件与练习：44—50

- **44 改进已有元素。** 项目符号和选中状态可增强扫描，真实状态仍由数据决定。文字已有含义时，不把新图标说成首次表达状态；装饰不能冒充确认。
- **45 克制使用强调边框。** 少量色边可以辅助区块识别，正文仍说清原因和下一步。相邻区域避免同样线索承担冲突含义。
- **46 背景装饰服务定位。** 内容层级成立后再比较纯色、纹理或渐变。图案低对比不等于文字低对比，装饰不拦截操作、不承担唯一状态。
- **47 按原因设计空状态。** 等待数据与权限确定后，区分首次、筛选无结果、请求失败和无权限。仓库接入、配置与运行按进度引导，不重复要求已完成的步骤。
- **48 删除重复而非必要边框。** 明确轮廓、分组、输入、选中和焦点职责，用空间或表面替代重复分隔。选择含义保留文字或标记，不能只剩底色。
- **49 重组外观并保留语义。** 重要互斥选择可用卡片集中名称、说明和状态，同时保留单选组、键盘与真实值。简单选择继续用普通单选也可以。
- **50 复现后解释决定。** 先独立复现，再逐项比较行高、间距、颜色、阴影和层级。真实长内容与异常状态通过后，整理为可复用规则，不用组合截图证明单项收益。
